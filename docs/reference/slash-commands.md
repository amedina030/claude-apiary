# Slash Commands

Slash commands are markdown files under each tool's `commands/` directory.
`apiary install --target <repo>` copies them to `<repo>/.claude/commands/<name>.md`,
which is where Claude Code loads them from — per repo, never from a global
directory. They are invoked by typing `/<name>`.

## Toggles

`/budgeter <log|session-warn>` creates or removes a sentinel file at
`<repo>/.claude/apiary/flags/<flag-name>-enabled`. Presence = enabled.

| Invocation | Flag file | Default |
|------------|-----------|---------|
| `/budgeter log` | `<repo>/.claude/apiary/flags/budgeter-log-enabled` | off |
| `/budgeter session-warn` | `<repo>/.claude/apiary/flags/budgeter-session-warn-enabled` | off |

Toggles are per-repo and persist across sessions. The skill shells out to
`core/flags.py` (see [CLI Tools](cli-tools.md#coreflagspy)), which is the same
code path the hooks read — so what the toggle writes is what they check.

One more flag exists with no slash command: `learnings-inject` gates the
PreToolUse learnings injector (`core/hooks/learnings_inject_hook.py`), and is
off unless you run `core/flags.py enable learnings-inject`.

## Always-active features

These have no toggle — they are always on wherever apiary is installed:

- **Scribe** (notes, learnings, handoffs) — `/note`, `/notes`, and the summary the startup hook injects
- **Session startup context** — injected by `core/hooks/startup_prompt_hook.py` on the first user message of every session
- **Transcript recording** — `core/hooks/save_transcript.py` writes `<state-dir>/sessions/` at the end of every assistant turn
- **The push gates** — the doc-conformer and secret-scan hooks block a `git push` that would carry doc drift or a credential
