Guidance only — no `required:` sections, so nothing here is enforced.

Context notes are mid-session checkpoints and auto-archive after 3 days, so
write for "me, later today or tomorrow":

- **Where things stand right now** — what is half-done and in which files.
- **What I was about to do next.**
- Anything held only in working memory: a command that worked, a value being carried around, a dead end just ruled out.
- If it is still true next month, it belongs in a learning or memory instead.
