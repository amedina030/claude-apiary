Guidance only — no `required:` sections, so nothing here is enforced.

A reference note is a durable lookup, so write it for a reader with no session context:

- **What this is** and when someone would need it.
- The actual content — command, path, schema, table — verbatim enough to copy.
- **Where it came from** (file path, URL, or "measured on 2026-08-26") so it can be re-verified.
- If it will be false in a month, it is a context note, not a reference.
