# claude-apiary

A unified ecosystem of tools that extend Claude Code. Run `/apiary-context` at session start to load the full apiary toolkit rules.

If the `load_apiary_context` context-rule is installed in `~/.claude/CLAUDE.md`, this happens automatically.

## Portability

Read `PORTABILITY.md` before writing or modifying any code, hooks, scripts, or `settings.json` entries.
